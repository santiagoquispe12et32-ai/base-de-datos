N.º 003

DER

Modelado de datos

El Diagrama Entidad-Relación es el mapa de la base de datos: muestra las entidades (tablas), sus atributos y cómo se relacionan entre sí, antes de escribir una sola línea de SQL.

Sintaxis

ENTIDAD
  - atributo (PK)
  - atributo
  ----< relación >----  OTRA_ENTIDAD

Ejemplo

ALUMNO (id_alumno PK, nombre)
   1 ----< N   INSCRIPCION >---- N   1   CURSO (id_curso PK, nombre)

PK = clave primaria (identifica cada fila). FK = clave foránea (conecta con otra tabla).
