N.º 011

DICCIONARIO DE DATOS

Documentación

Documento (o tabla) que describe cada campo de la base: nombre, tipo de dato, tamaño, si acepta nulos y para qué sirve. Es el "manual de instrucciones" de la base.

Sintaxis

Tabla | Campo | Tipo | Tamaño | Nulo | Descripción

Ejemplo

alumnos | id_alumno | INT | - | NO | Identificador único del alumno
alumnos | nombre    | VARCHAR | 50 | NO | Nombre completo del alumno

Se arma junto con el DER y sirve para que cualquiera entienda la base sin adivinar.
